# Computer Science Department Website

A responsive and modern website created as part of ICT Lab Task 10 at Air University, Aerospace & Aviation Campus Kamra.

## Project Overview

This project presents a sample departmental website for the Department of Computer Science. It provides information about academic programs, campus facilities, student resources, and other departmental sections.

## Features

- Modern and responsive website design
- Animated sections and interactive hover effects
- Department information and academic programs
- Campus gallery and facilities
- Student guide and sample timetable
- Registration form demonstration
- Audio and video media section
- Useful university links

## Technologies Used

- HTML5
- CSS3

## How to View

1. Open the repository.
2. Download the project files.
3. Extract the downloaded files if necessary.
4. Open `index.html` in a web browser.

## Note

This is an academic demonstration project created for an ICT laboratory assignment. It is not an official university website. Some multimedia content may depend on browser compatibility, internet access, and external content availability.
